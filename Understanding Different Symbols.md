Some of these are also listed in different files when context is necessary and isn't very common like $\Sigma$ is.

- $\epsilon$ (or Epsilon, lowercase) is used to represent an empty string or a blank area.
- $\Sigma$ (or Sigma, uppercase) is used to represent the list of possible characters able to be used, also known as an alphabet.
- $\cup$ (or union / cup) is used to conjoin two sets together.
- $\bigcup$ (or big union / big cup) is used to conjoin two *or more* sets together.
- $\in$ is used to represent the belonging to something. For example, $x \in y$ means $x$ belongs to $y$.
- $\notin$ is the inverse of $\in$.
- $\delta$ (or Delta, lowercase) is used to represent the [transition function ](obsidian://open?vault=Compilers&file=A%20Formalism%20for%20Recognizers).
